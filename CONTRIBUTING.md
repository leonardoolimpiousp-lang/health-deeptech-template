# Como contribuir

1. Escolha uma entrega verificável em `STATUS.md` ou abra uma issue com objetivo, fonte e critério de aceitação.
2. Crie branch curta; faça alterações focadas; abra PR com resumo, fontes, limitações e revisão necessária.
3. Para afirmações científicas, registre DOI/PMID/URL em `08_REFERENCIAS/matriz.md`, população, desenho e limitações. Separe associação, causalidade e hipótese.
4. Atualize `DECISIONS.md` para mudanças de direção e `CHANGELOG.md` para mudanças substantivas.
5. Peça revisão de especialista para afirmações clínicas, ética, segurança e regulação aplicáveis.

Nunca inclua no Git, issues ou PRs: dados identificáveis ou clínicos individuais, credenciais, contratos sigilosos e bases restritas. Use dados sintéticos ou agregados autorizados para exemplos. Valide autorização e aprovações antes de usar dados humanos.

## Checklist de PR

- [ ] Objetivo e critério de aceitação atendidos
- [ ] Fontes e limitações registradas
- [ ] Decisões e status atualizados quando necessário
- [ ] Nenhum dado sensível ou segredo incluído
- [ ] Links relativos e testes pertinentes conferidos
